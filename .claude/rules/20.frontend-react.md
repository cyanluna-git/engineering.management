# Frontend React Patterns

## Data Fetching: TanStack Query

All data fetching via hooks wrapping TanStack Query:

```typescript
// --- Correct: TanStack Query hook ---
export function useUsers(params?: { skip?: number; limit?: number }) {
  return useQuery({
    queryKey: ['users', params],
    queryFn: () => fetchUsers(params),
    staleTime: 10 * 60 * 1000,  // 10 min
  });
}

// --- Correct: Mutation with cache invalidation ---
export function useCreateProject() {
  const queryClient = useQueryClient();
  return useMutation({
    mutationFn: (data: ProjectCreate) => createProject(data),
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['projects'] });
    },
  });
}
```

```typescript
// --- Wrong: Direct fetch in component ---
function UserList() {
  const [users, setUsers] = useState([]);
  useEffect(() => {
    fetch('/api/users').then(r => r.json()).then(setUsers);
  }, []);  // No caching, no loading state, no error handling
}
```

## Component Structure

```typescript
// Imports → Types → Component → Export
import { useState } from 'react';
import { cn } from '@/lib/utils';

interface UserFormProps {
  onSubmit?: (user: User) => void;
  isLoading?: boolean;
}

export function UserForm({ onSubmit, isLoading = false }: UserFormProps) {
  const [name, setName] = useState('');
  return (
    <form className={cn('flex', isLoading && 'opacity-50')}>
      {/* ... */}
    </form>
  );
}
```

## Key Conventions

- **Functional components only** — no class components
- **Path alias:** `@/` maps to `src/`
- **Styling:** Tailwind CSS + `cn()` for conditional classes
- **UI primitives:** shadcn/UI (`components/ui/`)
- **All pages lazy-loaded** except LandingPage and LoginPage
- **Types centralized** in `types/index.ts`

## File Naming
- Components: `PascalCase.tsx`
- Hooks: `use*.ts`
- Pages: `*Page.tsx`

## Auth
- `useAuth` hook with localStorage token management
- Auto-refresh on 401 via Axios interceptor
- Roles: ADMIN, PM, FM, USER, GUEST, VIEWER
