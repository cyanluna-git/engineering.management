# Testing

## Backend (pytest)

### Structure
```
backend/tests/
├── test_users.py          # test_{entity_name}.py
├── test_projects.py
├── conftest.py            # Shared fixtures
└── integration/
    └── test_auth_flow.py
```

### Running
```bash
pytest                              # All tests
pytest tests/test_users.py -v       # Single file
pytest -k "test_create_user"        # By name
pytest --cov=app tests/             # Coverage
```

### Example
```python
def test_create_user(db_session: Session):
    service = UserService(db_session)
    user = service.create(name="John", email="john@example.com")

    assert user.id is not None
    assert user.name == "John"
```

## Frontend (Playwright E2E)

### Structure
```
frontend/tests/
├── auth.spec.ts
├── dashboard.spec.ts
└── worklogs.spec.ts
```

### Example
```typescript
test('should login with valid credentials', async ({ page }) => {
  await page.goto('/login');
  await page.fill('input[name="email"]', 'admin@edwards.com');
  await page.fill('input[name="password"]', 'password');
  await page.click('button:has-text("Sign In")');
  await expect(page).toHaveURL('/dashboard');
});
```
