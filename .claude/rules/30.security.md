# Security

## Authentication
- JWT access tokens (30 min) + refresh tokens (7 days) + registration tokens (24h)
- SSO/SAML 2.0 via Microsoft Entra ID
- Jarvis JWT Relay: separate JARVIS_SECRET_KEY for cross-service auth (10 min tokens)
- Roles: ADMIN, PM, FM, USER, GUEST, VIEWER
- GUEST/VIEWER are read-only (`require_write_permission()`)

## Secrets — Never Commit
- `SECRET_KEY`, `DATABASE_URL`, `POSTGRES_PASSWORD`
- `GROQ_API_KEY`, `GEMINI_API_KEY`
- `SAML_IDP_X509_CERT`
- `JARVIS_SECRET_KEY`

## Input Validation
- Pydantic models for all API input
- Parameterized queries only (SQLAlchemy ORM)
- No f-string SQL interpolation

## CORS
```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=settings.CORS_ORIGINS,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

## Password Hashing
- bcrypt via passlib (`CryptContext(schemes=["bcrypt"])`)

## Pre-Commit Checklist
- No hardcoded secrets
- All user input validated at system boundaries
- Error messages don't leak internals
