Preventability HIGH 분류 근거 및 한계

HIGH로 분류된 3가지 카테고리:

  • DESIGN_ERROR (39건)— reason 텍스트에 “design error”, “missing”, “wrong”, “incorrect”, “누락” 등의 키워드. 예: 볼트 위치 오류, 홀 누락, 공차 잘못, 포트 위치 반대. → 설계 단계 3D 리뷰/체크리스트로 사전 방지 가능
  • BOM_CORRECTION (15건) — BOM 입력 실수, 중복 등록, 구매 단위 오류, 2D/3D/ETO/SAP 간 불일치. → BOM 자동 비교 툴 또는 검증 프로세스로 방지 가능
  • DRAWING_UPDATE (16건) — 도면 심볼 오류, 텍스트 오타, 도면-실물 불일치. → 도면 릴리즈 전 peer review로 방지 가능
분류 한계: 키워드 기반 자동 분류로 일부 건은 과대 또는 과소 분류될 수 있습니다. 예를 들어 BOM_CORRECTION으로 분류된 일부 건은 실제로는 설계 개선이나 Supply Chain 이슈에 더 가까운 경우가 있습니다 (예: 구매품이 다르게 입고되어 BOM을 맞춘 경우). 정밀한 분류를 위해서는 각 건의 수동 검증이 필요하며, 70건 전체 목록은 별도 제공 가능합니다.

9. 개선 권고사항

즉시 실행 가능 (Quick Win)

  1. 병렬 승인 도입 — 순차 서명 → 동시 알림/병렬 서명. 승인 스프레드 46일 → ~15일 예상.
  2. 승인 SLA 설정 — Role별 7일 이내 서명. 미응답 시 자동 escalation.
  3. ECDP 작성 시 Impact Checklist — “인접 모듈 영향 검토 완료?” 체크 필수.
  4. 표준 부품 사전 확정 — Clamp, O-ring, Fastener 규격을 프로젝트 초기에 Lock.

중기 과제 (Process Change)

  1. 디지털 ECDP 시스템 — Excel → 웹 기반 폼. 연간 135인일 수작업 절감.
  2. Preventability 분류 의무화 — 작성 시 근본 원인 카테고리 선택 (12개 중 1개).
  3. Repeat Offender 분기 리뷰 — 같은 부품 3회+ 변경 시 자동 Flag → Design Review.

장기 과제 (Culture Change)

  1. Design Maturity Gate — 월 ECDP 발생률이 기준 초과 시 Gate 통과 불가.
  2. Cross-function ECDP Review Board — 월 1회, 고영향 ECDP 공동 리뷰.
  3. ECDP Zero 목표 — 양산 이관 후 6개월 내 ECDP 0건 달성 KPI.

이 보고서는 391건의 ECDP 문서 (5,416개 부품, 2,572건 승인 기록)를 기반으로 자동 생성되었습니다.
