소개

이 가이드는 네트워크 단절, ping 손실, 파일 업로드 오류가 발생한 Type 1 및 Type 2 컨트롤러의 복구 절차를 다룹니다. Digi 모듈 메모리가 손상된 경우 ESP와 JTAG 프로그래머를 사용해 모듈을 다시 플래시합니다.

3

✓ OK → 펌웨어 업로드 → 완료 ✗ NOK → 4단계로 이동
4
Flash Memory Sample
root.c에 브레이크포인트 설정 → 실행(플래시 삭제 3~4분)
✓ OK → rom.bin 및 image.bin 업로드 → 완료 ✗ NOK → 5단계로 이동
