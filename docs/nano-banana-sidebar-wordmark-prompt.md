# Nano Banana Prompt: E.O.B Sidebar Wordmark

## Goal
Redesign the left sidebar brand area for an internal web application called **Engineering Operation Board**.

The brand should feel like a **typographic wordmark**, not a generic startup logo, not an icon badge, and not a marketing hero section.
It must harmonize with an existing UI that already uses:

- dark slate sidebar
- bright Edwards-style blue accent
- clean enterprise dashboard layout
- minimal, practical, modern internal-tool tone

The design objective is to make **E.O.B** visually memorable while clearly showing that it means:

- Engineering
- Operation
- Board

The user prefers a text-only approach.

---

## Visual Direction
Create a refined **editorial / typographic lockup** inspired by the structure of the provided reference image style:

- strong vertical capital letters
- overlapping or tightly aligned full words
- compact, intentional spacing
- premium industrial-tech feeling

But adapt it to this product UI.

This should look like a brand mark that belongs inside a professional operations dashboard, not a consumer ad.

---

## Layout Requirements
Design a sidebar brand lockup for a **dark vertical sidebar**.

Use this structure:

- a strong vertical emphasis on `E`, `O`, `B`
- the full words `Engineering`, `Operation`, `Board` aligned so the relationship to `E.O.B` is instantly understood
- text should read as one cohesive composition, not three disconnected lines

Possible arrangement ideas:

- `E / O / B` as a left vertical spine, with the remaining word parts aligned on the right
- or a tightly stacked wordmark where the capital letters create a strong visual column

The composition should feel:

- compact
- precise
- balanced
- slightly bold
- elegant but not decorative

---

## Color Requirements
Use the existing product color language:

- sidebar background: very dark slate / navy-charcoal
- primary accent: the same vivid blue used in the product's Welcome card
- supporting text: white or very light slate

Important:

- do not introduce new brand colors
- do not use purple
- do not use orange
- do not use a rainbow palette
- keep the palette restrained and enterprise-appropriate

Recommended treatment:

- `E`, `O`, `B` in vivid blue
- remaining letters in white or soft near-white

---

## Typography Direction
The mark should rely on typography only.

Use these principles:

- bold uppercase initials
- tight tracking for the initials
- slightly compressed or optically dense word alignment
- subtle overlap or close stacking is acceptable
- line height should be tight enough to feel designed, but still readable

Avoid:

- playful rounded fonts
- handwritten style
- futuristic sci-fi style
- excessive italic slant
- generic AI-logo aesthetics

The result should feel like:

- industrial
- precise
- premium internal tool branding
- modern enterprise software

---

## Hard Constraints
Do **not** include:

- icon symbols
- sparkles
- gears
- abstract cubes
- circuit shapes
- gradient blobs
- 3D effects
- glossy logo treatments
- mascot style
- shield emblem
- app icon in a square tile

Do **not** make it look like:

- a startup landing page
- a crypto product
- a gaming UI
- a futuristic neon poster

This is for a real operations dashboard used by employees.

---

## UI Context
The wordmark will appear:

- at the top of a left sidebar
- above a blue welcome card
- inside a dark navigation rail
- next to a sidebar collapse button

So the wordmark must:

- remain visually strong in a small area
- not overpower the welcome card below it
- be legible at dashboard scale
- feel integrated with navigation UI

---

## Output Request
Please generate **3 distinct design directions** for the sidebar wordmark:

1. Conservative
2. Balanced
3. Bold

For each direction, show:

- the wordmark on a dark sidebar background
- the exact text `Engineering Operation Board`
- a version where `E.O.B` is clearly emphasized

Also provide a short rationale for each direction:

- why it fits an enterprise operations dashboard
- how it communicates `E.O.B`
- which option is best for production UI

---

## Preferred Outcome
The best result will likely be:

- text-only
- blue capital initials
- white supporting word fragments
- tight editorial alignment
- subtle overlap or compression
- highly readable
- elegant and industrial

The final feeling should be:

**"serious internal product, premium typography, blue industrial-tech identity."**
