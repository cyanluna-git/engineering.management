## Page 2: 배경 및 설계 원칙

### 현재의 문제

| 업무 상황 | 현재 방식 | 소요 시간 |
|-----------|-----------|-----------|
| "이 프로젝트에 SW 엔지니어 몇 명 투입 중이야?" | Excel 파일 찾기, 버전 확인, 수작업 취합 | **반나절** |
| "다음 분기에 우리 팀 여유 인력 있어?" | 각 PM한테 개별 문의, 답변 대기 | **수일** |
| "지난달 NPI에 실제 얼마나 투입됐어?" | SharePoint 리스트 다운로드, 피벗 테이블 작성 | **수시간** |
| "리소스 부족하다는 근거 데이터 보여줘" | 근거 자료 없음 | **불가능** |

### 왜 지금 해결해야 하는가

- **프로젝트 복잡도 증가**: EUV 프로그램 확대, NPI/ETO/CIP 동시 진행, 한 엔지니어가 2-3개 프로젝트에 동시 투입
- **인력 확보의 데이터화**: 리소스 부족을 "느낌"이 아닌 "데이터"로 증명해야 승인 가능
- **비용 투명성 요구**: Direct vs. Indirect 비용 구분, GAAP 준수 필요성 증가

### 설계 원칙: "넣는 건 쉽게, 분류는 상세히"

| | 기존 SharePoint (악순환) | Operation Board (선순환) |
|---|---|---|
| **입력** | 8-10 클릭, 2-3분 소요 → 귀찮음 | 2-3 클릭 또는 자연어 한 줄, 30초 이내 |
| **입력 후** | 블랙홀 (언제 취합될지 모름) | 즉시 내 대시보드에 결과 반영 |
| **데이터 활용** | 어쩌다 한 번 매니저가 피벗 테이블 | 매일 자동 집계, 실시간 리포트 |
| **프로젝트 반영** | 안 됨 | 리소스 계획에 직접 연동 |
| **팀원의 반응** | "이거 왜 넣어요? 어디 쓰이는지도 모르겠는데" | "내 FTE가 바로 보이니까 넣게 됨" |
| **매니저의 설득력** | 설득 근거 없음 | "하루 1분만 써줘, 이런 결과가 나와" |

## Page 3: 시스템 개요 및 핵심 기능 (입력 측)

### Project Operation Board - 3가지 핵심 가치

| 핵심 가치 | 설명 | 기존 대비 |
|-----------|------|-----------|
| **실시간 가시성** | 누가, 어디에, 얼마나 투입되는지 즉시 확인 | Excel 취합 반나절 → 즉시 |
| **데이터 기반 의사결정** | 과거 실적 + 미래 계획을 한 화면에서 비교 | 근거 없음 → FTE 데이터 기반 |
| **제로 수작업** | Excel 취합, 피벗 테이블, 수동 보고서 불필요 | 월 1-2일 → 자동 생성 |

### 기능 1: Smart Worklog - 일일 업무 기록

**입력 방법 A: 클릭 방식 (기본)**

| 기능 | 설명 |
|------|------|
| 스마트 디폴트 | 주 프로젝트, 최근 Activity 자동 선택 |
| 지난주 복사 | 반복 업무는 원클릭 복사 |
| 미팅 분류 | 의사결정 / 정보공유 / 피드백 / 문제해결 등 구분 |
| 긴급업무/출장 플래그 | 돌발 업무 및 출장 추적 가능 |

**입력 방법 B: AI 자연어 입력 (보조)**

```
입력: "오전에 OQC 프로젝트 미팅하고 오후에 NPI 407056 설계 작업함"
         ↓ AI 자동 분석
결과: ✅ 항목1 - OQC Infra / MEET / 4h (오전→4시간 자동 변환)
      ✅ 항목2 - ACM NPI 407056 / DESIGN / 4h (오후→4시간 자동 변환)
         ↓ 확인 후 저장 (틀린 부분만 수정 가능)
```

| AI 기능 | 설명 |
|---------|------|
| 자연어 인식 | "오전에", "오후에", "잠깐" 등 일상 표현을 시간으로 변환 |
| 프로젝트 자동 매핑 | 프로젝트명, IO 코드, 키워드로 정확한 프로젝트 연결 |
| 활동 자동 분류 | "미팅"→MEET, "설계"→DESIGN, "테스트"→TEST |
| 멀티 항목 분리 | 한 줄에 여러 업무를 쓰면 각각 별도 워크로그로 자동 분리 |

### 기능 2: 비용 자동 분류 (Context-Aware Classification)

사용자는 프로젝트 + 활동 + 시간만 입력하면, 시스템이 Context(부서, 프로젝트 유형, 활동 코드)를 분석하여 4가지 비용 버킷으로 **자동 분류** (95%+ 정확도)

| 비용 버킷 | 목표 비율 | 해당 업무 | GAAP |
|-----------|-----------|-----------|------|
| **Direct Product** | 60-70% | NPI, ETO, 핵심 R&D | 자본화 가능 |
| **Direct Project** | 10-15% | 고객 프로젝트, 커스텀 엔지니어링 | 자본화 가능 |
| **Indirect** | 15-20% | Field Support, Sales Support, 유지보수 | 비용 처리 |
| **Overhead** | <10% | 교육, 행정, 채용, 휴가 | 비용 처리 |

- 규칙 엔진 기반: 관리자 UI에서 분류 규칙 변경 가능 (코드 배포 불필요)
- 감사 추적: 모든 분류 결정에 매칭 규칙과 신뢰도 점수 기록

## Page 4: 핵심 기능 (관리/분석 측)

### 기능 3: 개인 대시보드 (My Dashboard)

로그인 즉시 확인 가능한 개인 리소스 현황:

| 구성 요소 | 내용 |
|-----------|------|
| **My FTE** | 이번 달 프로젝트별 투입 비율 (계획 vs 실적 비교 차트) |
| **업무 분류** | Product 업무 vs. Support 업무 비율 |
| **과부하 경고** | FTE > 1.0이면 빨간색 경고 표시 |
| **주간 워크로그** | 이번 주 기록 현황 요약 |
| **마일스톤** | 다가오는 Gate Review 일정 |

### 기능 4: 리소스 매트릭스 (Resource Matrix)

전체 조직의 리소스 배치를 **한 화면**에서 파악:

- **행(Y축)**: 팀원 이름 / **열(X축)**: 월별 (12개월+) / **셀**: 프로젝트별 FTE (색상 코딩)
- **TBD 포지션**: 미배정 자리를 노란색으로 표시 → 채용 필요 시점 식별

| 확인 가능 항목 | 설명 |
|---------------|------|
| 투입 현황 | 누가 어떤 프로젝트에 얼마나 투입되는지 |
| 과배정 식별 | FTE > 1.0인 팀원 즉시 파악 |
| 미래 계획 | 3-12개월 전방 리소스 계획 |
| 채용 Gap | TBD 포지션(미배정 자리) 위치와 시점 |

### 기능 5: 리소스 포캐스팅 (12개월 전방 계획)

| 기능 | 설명 |
|------|------|
| 월별 FTE 배분 | 프로젝트별 x 역할별 x 월별 투입 계획 |
| TBD 포지션 관리 | 아직 채용 안 된 자리를 미리 계획에 반영 |
| 동적 Capacity 계산 | 한국 공휴일, 휴가 자동 반영한 월별 가용 시간 |
| Gap 분석 | 필요 리소스 vs 가용 리소스 차이를 월별로 표시 |

포캐스팅 예시:

| 이름 | 4월 | 5월 | 6월 | 상태 |
|------|-----|-----|-----|------|
| 김철수 | 0.8 | 0.8 | 0.5 | 정상 |
| 이영희 | 1.0 | 1.0 | 1.0 | 주의 |
| 박준형 | 0.6 | 0.9 | **1.2** | **경고** |
| TBD-SW Eng | 0.5 | 0.8 | 1.0 | 미배정 |
| **팀 합계** | **2.9** | **3.5** | **3.7** | |
| **가용 Capacity** | **3.0** | **3.0** | **3.0** | |
| **Gap** | **-0.1** | **-0.5** | **-0.7** | **인력 부족** |

→ 6월 Gap -0.7 = 지금 채용을 시작하지 않으면 3개월 후 프로젝트 일정 지연

### 기능 6: 프로젝트 마일스톤 추적

- 표준 PCP Gate(G3, G5, G6) + 커스텀 마일스톤(Shipment, Commissioning 등)
- Target Date vs 실제 날짜 자동 비교, 지연일수 자동 계산
- 마일스톤 시점과 리소스 피크 구간을 연계하여 사전 인력 배치 가능

## Page 5: PM을 위한 핵심 가치 - 데이터 기반 리소스 증명

### 기존 방식 vs Operation Board

| | 기존 | Operation Board |
|---|---|---|
| **리소스 요청** | "팀이 바빠요. 사람이 부족해요." | "지난 6개월 평균 FTE 1.15, 월 팀원당 12h 초과 근무" |
| **매니저 반응** | "다 바쁘다고 하는데, 근거가 뭐야?" | "이 데이터면 충분하네. 채용 시작하자." |
| **데이터 준비** | Excel 정리 수일 소요 | 화면 공유 즉시 |

### PM이 즉시 활용할 수 있는 데이터

| 데이터 | 용도 |
|--------|------|
| **Planned vs Actual FTE 트렌드** (6개월) | 지속적 과부하 증명 → 인력 추가 요청 근거 |
| **FTE > 1.0 초과 빈도 히트맵** | 초과 근무가 특정 시기/프로젝트에 집중되는 패턴 파악 |
| **미배정 TBD 포지션 목록** | 채용 필요 시점과 역할 명확화 |
| **비용 버킷별 비율** | Direct Product 비율로 팀의 핵심 R&D 기여도 증명 |
| **월별 Capacity Gap** | 미래 인력 부족 시점 사전 예측 |

> **핵심**: "감"이 아니라 "팩트"로 이야기할 수 있게 됩니다.
> 데이터 없는 리소스 요청은 승인되지 않지만, 데이터 있는 리소스 요청은 거절하기 어렵습니다.

## Page 6: 전체 조직 확산의 필요성 및 도입 부담

### 왜 전체 조직이 써야 하는가: 네트워크 효과

| | 현재 (4개 부서) | 전체 조직 도입 시 |
|---|---|---|
| **리소스 가시성** | 우리 팀 안에서만 보임 | Cross-functional 전체 리소스 보임 |
| **프로젝트 리소스** | 일부 프로젝트의 일부 팀만 | 모든 프로젝트의 전체 투입 인력 |
| **FTE 데이터** | 부분적 (4개 부서 데이터만) | 조직 전체 Capacity 파악 |

| **의사결정 레벨** | 팀 레벨 | 프로그램/조직 레벨 |

> NPI 프로젝트에 Control, Mechanical, Electrical 팀이 모두 투입됩니다.
> 한 팀만 시스템을 쓰면 **1/3만** 보입니다. 전체가 쓰면 **프로젝트의 전체 그림**이 완성됩니다.

## Page 7: 자체 구축 역량 및 운영 성과

### 외부 SaaS vs 자체 구축 비교

| | 외부 SaaS (PLM, Jira 등) | Operation Board |
|---|---|---|
| **비용** | 라이센스 per user/month (50명 기준 연 수천만원) | 자체 인프라, 추가 비용 없음 |
| **커스터마이징** | 제한적, 벤더 의존 | 우리 프로세스에 100% 맞춤 |
| **데이터 소유권** | 벤더 클라우드 | 자체 서버, 완전한 통제 |
| **변경 속도** | 벤더 일정 의존 (수주~수개월) | 즉시 반영 가능 |
| **우리 프로세스** | 범용 기능을 억지로 맞춤 | Edwards PCP 프로세스 내장 |
| **한국 환경** | 글로벌 기준 | 한국 공휴일, 한글 지원 |

> 이 시스템은 외주가 아닌 **우리 엔지니어링 조직 내부에서 직접 설계하고 구축**했습니다.
> 우리의 PCP 프로세스, 조직 구조, 프로젝트 유형에 맞춰져 있으며,
> 이는 우리 조직의 **자체 SW 역량**을 보여주는 것이기도 합니다.

### 현재 운영 성과

| 지표 | 기존 (SharePoint/Excel) | 현재 (Operation Board) | 개선 |

| 리소스 현황 파악 | 반나절 (Excel 취합) | 즉시 (실시간) | **즉시** |
| 월말 보고서 작성 | 1-2일 | 자동 생성 | **자동화** |
| 리소스 포캐스팅 | 불가능 | 12개월 전방 | **신규** |
| Cross-project 가시성 | 개별 문의 | 한 화면 | **실시간** |
| 비용 분류 | 수동 또는 미분류 | 자동 95%+ 정확도 | **자동화** |

## Page 8: 향후 로드맵 및 제안

### 발전 로드맵

| Phase | 시기 | 주요 내용 |
|-------|------|-----------|
| **Phase 1 (현재)** | 완료 | 워크로그 관리, 리소스 매트릭스, 개인 대시보드, 프로젝트/마일스톤 관리, 비용 자동 분류, AI 입력 보조 |
| **Phase 2 (단기)** | 3-6개월 | 팀 대시보드 고도화, FTE>1.0 자동 경고, 모바일 최적화, Power BI 연동 |
| **Phase 3 (중장기)** | 6-12개월 | What-if 리소스 시뮬레이션, 투입 패턴 분석, Finance ERP(SAP) 연동, 조직 전체 최적화 리포트 |
| **Phase 4 (비전)** | 12개월+ | AI 기반 리소스 추천, 프로젝트 리스크 자동 감지, 글로벌 사이트 확장 |
